# 実験3　配布文書と使い方

PART 1 の 1.3.3「実験3：冒頭の指示は最後まで守られるか」で使います。

---

## 配る前に知っておくこと

この5つのファイルは、**同じ内容の長さ違い**です。冒頭に3つの決まりが書かれ、
末尾に質問が1つあります。**決まりは冒頭にしか書かれていません。**

学生は短いものから順に投げ、**どの長さから決まりが守られなくなるかを記録します。**

| ファイル | 文字数 | 目安トークン |
|---|---:|---:|
| `exp3_short.md` | 約1,200 | 約600 |
| `exp3_medium.md` | 約2,100 | 約1,000 |
| `exp3_long.md` | 約3,400 | 約1,700 |
| `exp3_xlong.md` | 約6,900 | 約5,700 |
| `exp3_xxlong.md` | 約12,100 | 約10,100 |

Ollamaの既定のコンテキスト長を超えるあたりで、挙動が変わります。
既定値はバージョンによって違うので、**どこで変わるかは環境ごとに異なります。**
それを各自が見つけるのが、この実験です。

---

## 冒頭に書いてある3つの決まり

```
1. 回答は箇条書き3点にすること。それ以上でも以下でもいけない。
2. 各項目は40字以内に収めること。
3. 前置きと後書きを書かないこと。箇条書きだけを出力すること。
```

守られたかどうかは、**目で見て判定できます。**採点者の主観が入りません。
実験の題材として、この点が重要です。

---

## 末尾の質問と、その答え

> この文書における「ピーク帯の注文の扱い」について説明せよ。

答えは第7章にあります。**どの長さの版でも、第7章は文書の中央付近に置いてあります。**

正解に含まれるべき内容は3点です。

- 正午から午後1時30分がピーク帯で、切り替えは店長が宣言する
- 調理時間の短いものから着手する（短時間優先）
- 同一テーブルをばらけさせない、アレルギー未確認は回さない、の2つが優先する

ちょうど3点なので、決まり1（箇条書き3点）とも整合します。

---

## 学生に渡す手順

1. `ollama run qwen3.5:4b` を起動する
2. `exp3_short.md` の**中身をすべて**貼り付けて実行する
3. 出力が3つの決まりを守っているかを記録する
4. medium、long、xlong、xxlong と順に上げていく
5. **決まりが崩れた最初の長さを記録する**

貼り付けは、ファイルを開いて全選択（`Ctrl` + `A`）してコピーします。

---

## 見てほしい崩れ方

崩れ方には段階があります。**「守られた／守られなかった」の2択で記録させないでください。**

| 段階 | 症状 |
|---|---|
| 1 | 3点だが、1項目が40字を超える |
| 2 | 前置きが付く（「はい、説明します」など） |
| 3 | 項目数が4つ以上、または2つになる |
| 4 | 箇条書きですらなくなる |
| 5 | 質問と関係のない内容を答える |
| 6 | 第7章の内容ではなく、文書の冒頭や末尾の内容を答える |

6番が出たら、それはコンテキストの中央が落ちた状態です。
**Lost in the Middle** がそのまま観測できています。

---

## 回収のことば

> 短い版では守られたのに、長い版では守られなくなりました。
> モデルが忘れっぽくなったのではありません。**入る量に限りがあるだけです。**
>
> Coding Agentが長い作業の途中で、最初に決めたルールを守らなくなるのは、
> これと同じことが起きています。PART 5で `AGENTS.md` を短く保つよう書くのは、
> このためです。長くすると、肝心の指示が埋もれます。

## より確実に見せたい場合

授業時間が短く、xxlong を待てない場合は、`num_ctx` を小さくした
実験用のモデルを用意しておくと、`exp3_short.md` でも崩れます。

```
# Modelfile.tiny
FROM qwen3.5:4b
PARAMETER num_ctx 512
```

```
ollama create qwen-tiny -f Modelfile.tiny
ollama run qwen-tiny
```

この方法だと、**現象が確実に、かつ数秒で起きます。**
ただし「自分の環境の限界を見つける」という体験は失われるので、
時間があれば長さを上げていく方法のほうを勧めます。

設定の詳細は付録AのA.3.2にあります。
